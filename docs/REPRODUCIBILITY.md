# Reproduction boundaries

The default review suite runs synthetic inputs and exact tiny-world references, not new native matches. The example invokes the actual Bayesian implementation on fictional decks. Full historical tests remain outside the default selection because many need private assets.

Full research runs additionally required lawfully obtained official SDK/card assets, a compatible native environment, exact deck catalogues, demonstration/belief corpora, selected pretrained/fine-tuned checkpoints, static/text tensors and frozen run metadata. Those are excluded.

Historical scripts retain private relative input references, experiment deadlines and safety guards. They are not a turnkey training service. Old registrations are evidence, not current authorization for compute spending, uploads or submissions. No credentials are required to inspect the portfolio.

No native adapter or policy algorithm was changed for this export. Full BO3 integration was not rerun for source/documentation curation. The report copies retain historical integration results and their dates. Local path/account sanitization and extraction of synthetic tests are export-only edits.

The recorded 3,105,473 parameter count belongs to the original model's historical card vocabulary and visible-v1 schema. Portable tests use tiny synthetic tables; they do not recreate that count. Later semantic projections can change parameter counts.

Unown is a separate upstream architecture. Its current-format assembly is included, but trained execution requires excluded weights/tables. Truth/oracle modules are offline label/diagnostic code; privileged state is not a legal policy input.

## Sensitive temporal data removed

Calendar dates, clock values and saved temporal metadata have been removed from this public copy at the owner’s request. Date-derived seed constants are replaced with neutral identifiers; their original values and the mapping are not included. Calendar years are omitted from public notices while authorship and license terms remain. Restore privately registered values before attempting historical run reproduction. This does not change the retained result tables or durations such as GPU-hours. The public source is for review and synthetic checks, with private training assets already excluded.
