# Unown source without weights

Model author: Dipam Chakraborty. MIT notice: [../../licenses/Unown-MIT.txt](../../licenses/Unown-MIT.txt).
Upstream commit: a176778d99da74a44b495bf19299b4795faf12f2.

ptcg/rl/model.py defines the released model. frozen_unown/runtime.py and units/ contain the project inference assembly/adaptation copied from its retained source export.

Four Transformer blocks, width 256, eight heads, feed-forward width 512; no neural recurrent layer. External tracking carries restricted legal deck facts. Conditional selections use live prefixes and STOP.

No weights, tensor embeddings, card/deck JSON, native binaries or trajectories are included. This is source for review, not a complete executable competition package.
